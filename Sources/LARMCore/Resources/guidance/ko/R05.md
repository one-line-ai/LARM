## 왜 위험한가
검토되지 않았거나 기준 상태 이후 바뀐 외부 도구 연결(MCP) 정의는 어떤 명령, 연결 주소가 에이전트에 연결되는지 사용자가 모른 채 남아 있을 수 있음. 버전이 고정되지 않은 `npx`/`uvx` 실행은 매번 다른 코드를 받을 수 있음.

## 확인할 위치
발견 사항의 선언 위치(설정 파일)와 명령 종류, 명령 내용 개수, 연결 주소 요약을 보기. LARM은 서버를 실행하거나 접속하지 않음

## 수정 전 확인
- 패키지 출처와 버전을 확인하고 `@버전`으로 고정함
- 필요 없는 서버는 정의를 삭제함

## 되돌리기
설정 파일에서 정의를 이전 상태로 되돌림

## 재점검
검토를 마치면 "기준 상태 지정"으로 알려진 구성 상태를 기록함. 기준 상태은 안전 인증이 아님.
