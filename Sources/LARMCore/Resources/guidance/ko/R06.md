## 왜 위험한가
평문 HTTP 원격 연결 주소는 경로상에서 내용이 읽히거나 바뀔 수 있음. 검토되지 않은 원격 호스트는 어디로 데이터가 가는지 사용자가 모름.

## 확인할 위치
scheme, host, port 요약을 보기. LARM은 URL의 userinfo, query, fragment를 저장하지 않음

## 수정 전 확인
- 회사 프록시, OAuth 연결 주소는 정상일 수 있음. 소유자, TLS 여부를 확인하기
- 인증 헤더가 보이지 않는다고 무인증으로 단정하지 않음

## 되돌리기
URL을 `https://`로 바꾸거나 정의를 제거함

## 재점검
검토를 마치면 "검토 완료"로 기록함 (정확한 host, scheme, port 단위).
