## 왜 위험한가
실행 전 확인를 생략하거나 파일, 네트워크 격리를 해제하면, 에이전트가 사용자 확인 없이 명령을 실행하거나 작업 폴더 밖을 읽고 쓸 수 있음. 두 설정은 별개 축이며 하나만 켜진 경우와 둘 다 켜진 경우의 위험이 다름.

## 확인할 위치
- Claude Code: `permissions.defaultMode` (settings.json), `sandbox` 설정 (S1, S2)
- Codex CLI: `approval_policy`, `sandbox_mode`, `profiles.<name>` (S3, S4)

## 수정 전 확인
- 관리(managed) 설정이 사용자 설정을 덮어쓰는지 확인함
- 실제 작업 세션에서 CLI 표시(`--dangerously-skip-permissions`, `--sandbox` 등)로 덮어쓰는 경우는 이 점검에서 확인되지 않음

## 되돌리기
설정 값을 이전 값으로 되돌리면 됨. LARM은 파일을 변경하지 않으므로 벤더 설정 파일을 직접 편집하기

## 재점검
값을 바꾼 뒤 "재점검"을 누르면 같은 범위, 같은 룰로 다시 읽음.
