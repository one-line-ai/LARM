LARM · 요금제 안 · 2026-09-26

요금제별 기능 구성

Basic은 지금 설치된 0.7.0 그대로이며 무료다. Pro와 Enterprise는 아직 만들지 않은 계획으로, 여기서는 어떤 기능이 어느 단계에 들어가는지를 정한다. 가격은 월 요금이며, Pro는 사용자 1명, Enterprise는 팀(10석 포함) 기준으로 가정한다.

나누는 기준. 혼자 쓰는 Mac 한 대의 안전은 무료로 다 준다(Basic). 판단을 더 정확하게 하고 더 오래 기억하는 것은 Pro. 여러 사람·여러 Mac을 한 곳에서 관리하고 감사에 내야 하는 것은 Enterprise.

2. 모든 요금제에서 같은 것

  • 관측 모드: 허용·차단 결정을 하지 않음(F42·F43 제외 유지). 설정 파일을 고치지 않음.
  • 비밀값·실제 경로는 저장·전송하지 않음. 활동 기록은 종류·개수·요약값·표시만.
  • 결정은 사람이 함. 추정값은 항상 "참고"로 표시.
  • Enterprise의 팀 대시보드도 개인 Mac의 원문 데이터가 아니라 집계와 별칭만 받음.
